# Anolis OS 简介

Anolis OS（龙蜥操作系统）是龙蜥社区发布的开源 Linux 发行版。

## 1. 主要特点
- 生态兼容：Anolis OS 8 与 CentOS 8 生态兼容，大部分软件可以直接迁移使用；
- 多架构：支持 x86_64 和 aarch64 等主流架构；
- 内核：默认搭载社区维护的 ANCK 内核。

## 2. 适用场景
适用于云服务器、数据中心以及需要长期稳定运行的企业业务。对于 CentOS 停止维护后需要寻找替代系统的用户，Anolis OS 是常见选择之一。

## 3. 获取方式
可以从龙蜥社区官网的下载页面获取 ISO 镜像，也可以使用社区提供的容器镜像和云上镜像。
