# 从 CentOS 迁移到 Anolis OS

CentOS 8 停止维护后，可以使用龙蜥社区提供的迁移工具把系统原地迁移到 Anolis OS，业务数据和配置会保留。

## 1. 迁移前准备
- 备份重要数据，最好给机器做一个快照；
- 确认系统版本在迁移工具的支持范围内；
- 检查第三方软件源，迁移过程中可能需要临时禁用。

## 2. 执行迁移
下载迁移脚本 centos2anolis.py 后，以 root 用户执行。脚本会替换软件源、重新安装系统相关的软件包。

## 3. 迁移后检查
迁移完成后重启机器，执行 cat /etc/os-release 确认系统已经变成 Anolis OS，并检查业务服务能否正常启动。
