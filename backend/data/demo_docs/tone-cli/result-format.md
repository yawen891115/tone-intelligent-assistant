# tone-cli 结果目录与格式

## 1. 结果存放位置
每次 tone run 都会在结果目录下按测试套件和时间创建一个子目录，里面包含原始日志、解析后的结果文件和环境信息。

## 2. 功能测试结果
每一行表示一个用例的结果，状态取值为 Pass、Fail、Skip。

## 3. 性能测试结果
每一行是一个指标，例如 throughput: 1234.5，单位在指标名中注明。重复运行多次时，平台会根据多次结果计算平均值和波动。

## 4. 上传到平台
联网的机器由 ToneAgent 自动回传结果；不能联网的机器使用 tone archive 打包后，在平台「离线上传」页面上传。
