# Job 模板与测试计划

## 1. 保存为模板
创建 Job 时，如果这组配置以后还会反复使用，可以点击「存为模板」。下次创建测试时选择模板，所有参数会自动带出，只需要改动少量字段。

## 2. 测试计划
测试计划用于定期、批量地执行测试。一个计划由多个阶段组成，每个阶段包含若干个 Job 模板。

## 3. 定时触发
在测试计划中开启定时触发，使用 cron 表达式设置运行时间。例如 0 2 * * * 表示每天凌晨 2 点执行一次。也可以通过 API 在代码合入后由 CI 系统触发。

## 4. 结果汇总
计划执行完成后，平台会把所有阶段的结果汇总到一个计划结果页面，并可以一键生成测试报告。
