# 测试机器接入说明

本文介绍如何把你自己的服务器添加到 T-One 平台，让平台调度它执行测试。也可以使用云账号动态创建机器，见《弹性机器池与云上机器》。

## 1. 机器网络要求
被测机器需要能主动访问 T-One 服务端地址，同时平台也要能连到机器上的 ToneAgent。如果机器在内网，请确认防火墙放行了对应端口。

## 2. 添加机器至 T-One 平台
### 2.1 进入你的 Workspace
登录 T-One，进入要使用这台机器的 Workspace。

### 2.2 打开机器管理页面
点击「设置 - 机器管理」，根据用途选择「固定机器池」或「弹性机器池」。固定机器池用于长期保留的物理机或虚拟机。

### 2.3 添加机器
点击「添加机器」，填写机器 IP、机器名称、架构等信息后提交保存。提交后平台会自动为这台机器生成一个唯一的 TSN（机器序列号），后面安装 ToneAgent 时要用到。

## 3. 安装 ToneAgent 服务至机器
在机器上安装 ToneAgent，并把上一步生成的 TSN 和平台地址写进 ToneAgent 的配置文件，然后启动服务。详细步骤见《ToneAgent 安装与排障》。

## 4. 检查机器状态
### 4.1 在机器上检查
执行 systemctl status toneagent，确认服务处于 active (running) 状态。
### 4.2 在平台上检查
回到机器管理页面，机器状态显示为 Available 即表示接入成功，可以被 Job 调度。
