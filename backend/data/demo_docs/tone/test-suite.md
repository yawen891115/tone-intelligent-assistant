# 测试套件管理

## 1. 功能测试与性能测试
测试套件分为两类：
- 功能测试：关注用例是否通过，结果是 Pass / Fail / Skip；
- 性能测试：关注指标数值，例如吞吐量、延迟，结果会和基线比较。

## 2. 系统级套件和 Workspace 套件
系统管理员在「系统配置 - 测试套件」中维护全局的测试套件库。各个 Workspace 需要先把套件添加到自己的 Workspace，之后创建 Job 时才能选择。

## 3. Test Conf
一个测试套件下可以有多个 Test Conf，每个 Test Conf 是一组具体参数的组合。例如同一个网络性能套件，可以分别配置不同的消息大小和并发数。创建 Job 时可以只选择部分 Test Conf。

## 4. 设置默认参数
在套件详情里可以设置超时时间、重复次数等默认值。重复次数大于 1 时，性能测试会自动计算多次结果的平均值和波动。
