# 创建测试 Job

Job 是 T-One 中执行测试的基本单位。

## 1. 选择测试类型和套件
进入 Workspace，点击「新建测试」，先选择测试类型（功能 / 性能），再从已添加到 Workspace 的测试套件里勾选需要运行的套件和 Test Conf。

## 2. 选择机器
机器的分配方式有三种：
- 指定机器：直接选择一台或多台机器；
- 随机分配：从机器池中自动选择一台空闲机器；
- 按标签调度：选择机器标签，平台会在带有该标签的空闲机器中挑选。

## 3. 环境准备
在「环境准备」中可以配置测试前要做的事情，例如重启机器、安装指定内核、执行自定义脚本。

## 4. 提交与状态
提交后 Job 会依次经历 pending（排队中）、running（运行中），最后变为 success、fail 或 stop。点击 Job 可以实时查看每个步骤的执行日志。
