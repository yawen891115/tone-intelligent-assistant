# 在测试中安装指定内核

验证新内核时，经常需要先在机器上装好被测内核再跑测试。

## 1. 登记内核
系统管理员可以在「系统配置 - 内核管理」中登记常用的内核版本，填写 kernel、devel、headers 三个 rpm 包的下载地址。

## 2. 在 Job 中安装
创建 Job 时，在「环境准备 - 安装内核」中选择已登记的内核，或者直接填写 rpm 包地址。平台会先安装内核再重启机器，重启完成后才开始执行测试。

## 3. 验证
测试开始前，平台会执行 uname -r 检查当前运行的内核版本是否与期望一致。如果不一致，Job 会在环境准备阶段失败，请检查 rpm 地址是否可以下载、机器的默认启动项是否正确。
