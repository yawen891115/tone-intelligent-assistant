# 弹性机器池与云上机器

除了接入自己的固定机器，T-One 还可以使用云账号按需创建测试机器，测试完成后自动释放。

## 1. 配置云账号
在「设置 - 云上配置」中添加云账号的 AccessKey 和 Secret，以及默认的地域。

## 2. 配置机器规格
在弹性机器池中添加云上机器配置，包括镜像、实例规格、系统盘大小等。

## 3. 自动创建与释放
Job 运行时如果选择了弹性机器池中的配置，平台会自动创建实例、安装 ToneAgent 并执行测试，测试结束后按设置自动释放实例，避免产生额外费用。

## 4. 注意事项
云上机器按量计费，请合理设置释放策略；如果需要保留现场排查问题，可以在 Job 中选择"测试完成后不释放"。
