# Workspace 管理

## 1. 创建 Workspace
在首页点击「创建 Workspace」，填写名称、简介，并选择公开或私有。公开的 Workspace 所有人可见，加入时需要管理员审批；私有 Workspace 只有成员能看到。

## 2. 成员与角色
Workspace 内有四种角色：
- 所有者：拥有全部权限，可以转让或注销 Workspace；
- 管理员：管理成员、机器、测试套件等配置；
- 测试人员：可以创建 Job、编辑报告；
- 普通成员：只能查看。

## 3. 申请加入
在 Workspace 列表中点击「申请加入」，填写申请理由。管理员会在「成员管理 - 加入申请」里看到申请并审批，审批结果会通过消息通知告诉你。

## 4. 注销 Workspace
注销属于高风险操作，需要所有者发起并经过系统管理员审核，注销后 Workspace 下的数据将无法恢复。
