# Job 失败排查

Job 失败时，可以先使用答疑助手中的「自助排查」，输入 Job ID 自动诊断常见问题。也可以按下面的顺序手动排查。

## 1. 系统调度阶段
机器离线或者 ToneAgent 心跳超时，会导致步骤无法下发。先确认机器状态是否为 Available。

## 2. 测试准备阶段
- 用例下载失败：检查机器是否能访问代码仓库或下载地址；
- 磁盘空间不足：清理机器上的历史测试数据；
- 内核安装失败：检查 rpm 地址和启动项。

## 3. 执行用例阶段
查看失败步骤的日志，找到第一条报错。若是用例本身的问题，可以在结果页标注为"用例问题"。

## 4. 测试结果阶段
结果解析失败时，通常是测试工具的输出格式发生了变化，需要更新结果解析脚本。
