# 机器标签与调度

## 1. 为什么需要标签
当机器池里有很多机器时，可以用标签描述机器的特征，例如 x86_64、aarch64、大内存、NVMe 盘等。创建 Job 时按标签调度，就不用手动挑选具体机器。

## 2. 添加标签
在「机器管理」中编辑机器，选择或新建标签。一台机器可以有多个标签。

## 3. 机器状态
- Available：空闲，可以被调度；
- Occupied：正在被某个 Job 占用；
- Broken：机器故障，暂停调度；
- Offline：ToneAgent 失去连接。

## 4. Job 一直排队怎么办
如果 Job 长时间处于 pending 状态，通常是因为没有满足条件的空闲机器：例如指定的机器正被其它 Job 占用，或者带有该标签的机器全部处于 Broken、Offline 状态。可以在机器管理中查看机器当前被哪个 Job 占用。
