# T-One 平台概述

## 1. T-One 是什么
T-One 是龙蜥社区的一站式自动化测试平台，覆盖从测试准备、测试执行到结果分析的完整流程。开发者可以在平台上管理测试机器、编排测试任务，并对多次测试的结果做对比，判断一个内核或软件版本是否引入了回归。

## 2. 核心概念
- Workspace：团队的工作空间，机器、测试套件、Job 和报告都归属于某个 Workspace。
- 测试套件（Test Suite）：一组测试用例的集合，分为功能测试和性能测试两类。
- Job：一次具体的测试任务，指定在哪些机器上运行哪些测试套件。
- 基线：记录"已知正常"的结果，用来自动判断新结果是否异常。

## 3. 版本说明
T-One 提供社区在线版和开源版两种形态。开源版可以部署在企业内网，前端项目是 tone-front，后端是 tone-web，命令行工具是 tone-cli。
