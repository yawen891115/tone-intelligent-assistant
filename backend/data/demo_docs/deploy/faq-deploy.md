# 开源部署 FAQ

## 1. 端口被占用
启动脚本报端口冲突时，先用 ss -lntp 查看是哪个进程占用了端口，停掉冲突的服务，或者修改 docker-compose 文件中映射的端口后重新启动。

## 2. 数据库连接失败
后端容器日志中出现数据库连接错误时，确认数据库容器已经正常启动，并检查配置中的数据库地址、用户名和密码是否一致。

## 3. 打开页面白屏
前端页面白屏一般是静态资源加载失败。按 F12 打开浏览器控制台查看报错，确认前端容器正常运行、反向代理配置正确。

## 4. 如何升级
拉取 tone-deploy 的最新代码，重新执行部署脚本即可。升级前请先备份数据库。
